# AXIS Corporate — Website preview

Projeto independente em HTML, CSS e JavaScript, seguindo a linha de produção do site oficialdanielvieira.com.br.

## Estrutura
- `index.html` — página institucional
- `assets/css/style.css` — identidade visual e responsividade
- `assets/js/main.js` — menu mobile e ano automático
- `assets/img/` — imagens de IA para validação visual

## Publicação
O projeto está preparado para GitHub Pages. Criar um repositório novo e enviar todo o conteúdo desta pasta para a raiz do repositório. Depois, habilitar Pages na branch `main`, pasta `/root`.

Antes de publicar no domínio oficial, validar textos, imagens, contatos e links.
